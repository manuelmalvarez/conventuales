# conventuales

Sitio web para una residencia universitaria. En producción en [conventuales.com.uy](https://conventuales.com.uy).

Vite + HTML/CSS/JS, con un plugin propio para reutilizar header/footer entre páginas sin backend, y procesamiento de imágenes (conversión HEIC + optimización) para la galería de fotos.

Deploy automático a GitHub Pages con GitHub Actions en cada push a `main`.

Construido en gran parte con asistencia de IA.
